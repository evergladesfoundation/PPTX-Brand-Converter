# Templates

`everglades.pptx` in this folder is the **server template** the rebrand engine inspects.

Until Communications provides the official `TEMPLATE.pptx` / `.potx`, the file here is a **generated stand-in** from `converter/build_template.py` (python-pptx default 16:9 layouts + Foundation theme colors). It is not brand truth. Drop the official file in place — if it is a `.potx`, `rebrand/inspect_template.py` rewrites it to `.pptx`.
